# Submission assets

- `devpost.json`: English project description, technology list, and source disclosure.
- `architecture.png`: architecture gallery image.
- `architecture.svg`: scalable, editable version of the same image.
- `architecture-write-path.mmd` and `architecture-read-path.mmd`: editable diagram sources.

Run instructions and credential-free testing are in the repository README. The public fixture uses synthetic data and is sufficient to reproduce the documented behavior.

The official rules require a public demonstration video of at most five minutes and an AWS Builder ID in the submission. Those are Devpost submission fields, not proof supplied by this repository. Video scripts and recording drafts are not included in this source package.

Rules: https://agentsforhumans.devpost.com/rules
